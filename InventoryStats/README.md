# InventoryStats — 牌库与遗物统计

HUD 在屏幕左下角显示三项合计：

- **念灵＋牌灵**：`18(8)` 表示牌库有 18 种牌永久附有念灵或牌灵，其中 8 种是念灵。
- **宝牌＋负面宝牌**：`12(3)` 表示牌库有 12 种牌永久附有宝牌，其中 3 种是负面宝牌。
- **诅咒遗物**：当前持有且带「诅咒」标签的遗物件数。

同一种牌同时有牌灵和宝牌时，两项各计 1；临时附着不计入。重复持有的遗物按件计数。

## 安装与配置

运行仓库根目录的 `install_mods.bat`，选择 **6**。在 `BepInEx/plugins/InventoryStats.yml` 设置：

```yaml
display: bag
```

- `bag`（默认）：打开地图或牌桌上的背包时显示。
- `always`：本局地图和牌桌上常驻显示，大厅隐藏。

修改后重启游戏。
